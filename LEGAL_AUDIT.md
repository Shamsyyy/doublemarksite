Объект: сайт https://doublemark.ru/ и репозиторий `DubliMarkSite`, плюс API `DoubleMark.Api` / PostgreSQL на VPS.

Источники норм, которые удалось подтвердить по официальному опубликованию:

- ФЗ от 24.06.2025 № 156-ФЗ, номер опубликования [0001202506240021](https://publication.pravo.gov.ru/document/0001202506240021). Статья 5 дополняет ч. 1 ст. 9 152-ФЗ: согласие на обработку персональных данных должно быть оформлено отдельно от иных информации и (или) документов, которые подтверждает и (или) подписывает субъект.
- ФЗ от 28.02.2025 № 23-ФЗ, номер опубликования [0001202502280034](https://publication.pravo.gov.ru/document/0001202502280034) — изменения в 152-ФЗ, в том числе в части ст. 18. Полный текст ч. 5 ст. 18 из официального файла в этой сессии загрузить не удалось (таймаут publication.pravo.gov.ru); оценка локализации сделана по факту архитектуры, без выдуманной цитаты.
- ФЗ от 26.07.2026 № 265-ФЗ, номер опубликования [0001202607260024](https://publication.pravo.gov.ru/document/0001202607260024) — изменения в ст. 12 152-ФЗ (трансграничная передача). Полный текст из официального файла в этой сессии также не загружен; вывод ниже основан на фактических получателях данных в коде.

Реквизиты оператора внесены владельцем 24.08.2026 в `src/config/legal.ts` (ИП, ИНН, ОГРНИП, адрес, email, банк). Старые заглушки `ООО/ИП DoubleMark` / ИНН `000000000000` не используются. Это не доказательство уведомления РКН и не 100% соответствие 152-ФЗ.

## Network audit (сборка, не живой браузер production)

Живой HTML `https://doublemark.ru/` в этой сессии загрузить не удалось (таймаут). Проверена production-сборка `dist/` от 17.08.2026:

`dist/index.html` **не** содержит `fonts.googleapis.com`, `fonts.gstatic.com`, Metrika, GA, GTM, Facebook, Supabase.

Шрифт Inter лежит в `dist/assets/inter-*.woff2` (SIL OFL, пакет `@fontsource/inter`).

### Ожидаемые внешние домены

**До consent (первый визит, без сессии):**

- `doublemark.ru` — документ, `/assets/*.js`, `/assets/*.css`, `/assets/inter-*.woff2`, `/brand/*`, `/manifest.webmanifest`
- API не вызывается, если нет `doublemark_api_session`

**После «Отклонить необязательные»:**

- тот же список first-party
- `POST https://api.doublemark.ru/api/consent` (после деплоя API) — без IP, без ФИО; только категории

**После «Принять»:**

- тот же список
- аналитический third-party JS **не загружается** (реестр `OPTIONAL_TRACKERS` пуст)
- тот же `POST /api/consent`

Необязательный аналитический/маркетинговый tracker до разрешения стартовать не должен.

Production-сборка через `npm run deploy` подставляет `VITE_API_BASE_URL=https://api.doublemark.ru`. Локальный `npm run build` без этих переменных ходит на `http://localhost:5080`.
